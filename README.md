# ESN Website

Official GitHub source for the ES Network website rebuild.

## Status
Development rebuild. The current live site at https://esnoffical.com remains untouched until the replacement is fully tested.

## Goals
- Preserve all current public ESN routes and content.
- Fix fragile navigation and 404 behavior.
- Improve performance, mobile UX, accessibility, SEO, and maintainability.
- Keep ESN SMP store/payment destinations intact during migration.
- Preserve the Arcade games and their existing gameplay/save behavior during the later migration phase.

## Development
This project uses Vite + React. After the initial scaffold is committed:

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```
